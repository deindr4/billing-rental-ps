2026-10-04 (perbaikan login lewat Cloudflare Tunnel)
-----------------------------------------------------------------------------
- Gejala: lewat domain tunnel gagal login, lokal aman. Penyebab: proxy tidak dipercaya -> halaman https memuat
  CSS/JS & Livewire lewat http -> diblokir browser. Patch mengisi TRUSTED_PROXIES=127.0.0.1,::1 + jaringan lokal

- Halaman Cloudflare Tunnel: baris "Proxy tepercaya" (merah bila kosong) + daftar cek (Rocket Loader, Bot Fight Mode).
