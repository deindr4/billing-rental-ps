TV
- Panel TV di kasir (ikon TV di kartu unit): tombol "Bypass" menjadi "Unlock" (pilih menit, PIN),
  tombol baru "Lock" (akhiri unlock & kunci lagi aplikasi TV, tanpa PIN) dan "Tutup aplikasi" (PIN).
  Status "Aplikasi ditutup (TV bebas)" tampil di panel. Butuh APK TV 0.5.0.
- Keamanan: perintah tutup aplikasi & update APK tidak bisa dikirim lewat tombol remote kartu unit.
- Pengaturan baru per cabang: Pengaturan -> Operasional -> Sesi & TV -> "Kepekatan timer di TV (%)"
  (30-100%, bawaan 90%). Butuh APK TV 0.4.2 ke atas.

Rilis & update APK TV
- Push update APK manual dari admin: per TV, TV terpilih, atau semua TV
  (Perangkat TV & Rilis APK TV), dengan pilihan "pasang sekarang juga walau TV dipakai".
- Kolom "Versi app" di Perangkat TV: kuning = belum terbaru, hijau = terbaru.
- Daftar Rilis APK bisa dilihat Owner (menu Rental, hanya baca + push ke TV miliknya),
  tombol Unduh APK per rilis.
- Tombol "Tarik" rilis bermasalah & "Rollback ke versi ini" (panduan + skrip
  tv-agent/build-rollback.ps1). Panduan: docs/rilis-apk.md.

Keamanan & kesiapan publik
- Pembayaran online tidak bisa diproses dua kali walau callback gateway & pengecekan
  berkala datang bersamaan (mencegah isi ulang waktu ganda).
- Dukungan Cloudflare / reverse proxy: TRUSTED_PROXIES di .env (IP pengunjung & https terbaca benar).
- Header keamanan di semua halaman (anti clickjacking, nosniff, HSTS saat https).
- "Simulasi bayar" di server produksi hanya untuk Owner.
- Halaman Pemeliharaan memperingatkan password bawaan, gateway simulasi, alamat aplikasi.

Admin & sistem
- Halaman baru Pengaturan -> Pemeliharaan sistem: tombol Optimalkan, Bersihkan cache,
  Kosongkan cache data, Update database (migrasi), Pasang ulang trigger sinkron,
  Tautkan folder unggahan, Restart antrean, Restart realtime; kondisi sistem; log error.
- Perintah "php artisan superadmin": buat super admin di server baru / reset password.
- Sinkronisasi: tombol "Buat token acak" di server lokal + kolom "Token dari server lokal"
  di cloud; tautan langsung ke halaman token cloud.
- Unggahan (wallpaper, logo, foto) tidak lagi macet "Memuat" bila admin dibuka lewat
  alamat selain APP_URL (localhost / IP LAN / domain).
- Batas waktu unggah file besar (APK / backup) 30 menit.

Publik
- Billboard: jam & timer per TV langsung terisi (tidak berkedip "--:--").


2026-09-30
-----------------------------------------------------------------------------
Pembayaran online & bayar mandiri di TV
- Payment gateway pilihan: Tripay, Midtrans, Duitku, iPaymu, DOKU, Simulasi (uji tanpa akun);
  Winpay menyusul (akun belum ada). Kunci rahasia disimpan terenkripsi, tombol Tes koneksi.
  Menu: Admin -> Pengaturan -> Pembayaran online.
- Bayar mandiri: pelanggan scan QR di TV -> ketik nominal di HP -> bayar QRIS di TV ->
  sesi dimulai otomatis (waktu = nominal / tarif per jam; nominal = harga paket -> paket).
  Hanya saat kas buka, minimal 30 menit (bisa diatur), maks. 12 jam sekali bayar.
- Isi ulang waktu lewat QR saat waktu habis; kasir tetap bisa tambah manual & tagihan
  menampilkan bagian yang sudah dibayar online (metode "QRIS online").
- Menu kasir "Pembayaran online": daftar tagihan, status, tindakan bila perlu.
- Sesi bayar mandiri yang habis & lunas diselesaikan otomatis.
- Pengaturan per cabang: Pengaturan -> Operasional -> Bayar mandiri di TV.

Perbaikan penting
- Waktu mulai sesi / buka kas / waktu bayar tidak lagi ikut berubah setiap data diubah
  (kolom waktu MariaDB). Sebelumnya masa pilih game bisa ter-reset.

Tahap 13 - Publik (revisi)
- Billboard jadi halaman link untuk HP (responsif), tanpa panggilan antrean.
- Menu F&B dihapus dari billboard; diganti iklan bergambar dengan masa tayang
  (Admin -> Rental -> Iklan billboard; otomatis terhapus saat habis).
- Status BUKA / TUTUP mengikuti kas, jam operasional tampil (Pengaturan -> Operasional).
- Semua gambar unggahan dikompres otomatis ke WebP; perintah "php artisan gambar:kompres".
- Wallpaper layar kunci TV per unit / umum langsung terlihat di TV.
- /admin/rental diarahkan ke daftar unit; tombol ke admin untuk Owner di aplikasi kasir.
